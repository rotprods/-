## Causality / hardness

The family language follows existing UMBRA constraints rather than random variation:
- dark structural metal = load-bearing body;
- ivory = replaceable service/repair surfaces;
- amber = refuge/service semantic light only;
- vermilion = hazard/hostile semantic only where justified;
- gasket material = protected seals/cable interfaces;
- thermal copper = heat-transfer function;
- tension fabric = insulation/repair material.

State variation is currently geometry-coded:
- `SERVICED`: visible service plate / renewed interface;
- `USED`: wear guard / contact-zone reinforcement;
- `FIELD_REPAIRED`: replacement patch + clamp or family-specific repair cue.

Uniform random scratches, procedural grunge, decorative decals and meaningless microgreeble were not introduced.
